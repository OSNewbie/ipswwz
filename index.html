🌐 CDN 四层证据链检测说明

为什么不能只看 IP 段？厂商 IP 段频繁增减，Azure 等 CDN 与普通云服务器共享 IP 段，单靠 IP 段误报率高。ASN 是路由层面的归属标识，比 IP 段稳定得多。

  • ASN 查询（核心）：通过 Team Cymru DNS 服务查询每个解析 IP 的 ASN，匹配 CDN 厂商的已知 ASN 列表（Cloudflare AS13335 / CloudFront AS16509 / Fastly AS54113 / Akamai AS20940 / Azure AS8075）。原理参考
  • CNAME 特征：解析链中出现厂商专属域名（.cloudflare.net / .cloudfront.net / .fastly.net / .akamaiedge.net 等）
  • HTTP 响应头：cf-ray / cf-cache-status（Cloudflare）、x-amz-cf-id / x-amz-cf-pop（CloudFront）、x-served-by / x-cache（Fastly）、server: cloudflare 等
  • 多地 Ping：通过接口盒子 pingplus 从全球 20+ 节点探测，收集不同地区解析到的 IP，再次跑 ASN 匹配
