关于

数据来源、使用说明

📌 数据来源

  • tcp.lc：IP 归属、DNS、Whois、ICP、SSL
  • ip.sb：备用地理与出口 IP
  • Shodan InternetDB：端口与漏洞测绘
  • Google DoH：DNS 综合解析
  • crt.sh：证书透明日志子域名枚举
  • Domainee：SSL 证书检测
  • URLhaus / OTX / ContrastAPI / Feodo Tracker：社区威胁情报
  • VPNDetection / NetRiskScan / ProxyCheck：VPN / 代理 / Tor 检测

📊 质量评分规则

IP 评分（满分 100）

  • 命中 Feodo C2 黑名单：-35
  • URLhaus 存在恶意 URL：-25
  • OTX 威胁 Pulse：每个 -5，最多 -20
  • AbuseIPDB 评分：按比例最多 -20
  • VPN / 代理 / Tor：-15
  • 开放高危端口（21/23/135/139/445/1433/3306/3389/6379/27017）：每个 -5，最多 -20
  • 已知漏洞（CVE）：每个 -5，最多 -15

域名评分（满分 100）

  • URLhaus 存在恶意 URL：-30
  • OTX 威胁 Pulse：每个 -5，最多 -20
  • SSL 证书无效：-25
  • 未配置 SPF：-5；未配置 DMARC：-5
  • 未查询到 ICP 备案：-10

分数仅供参考，不能替代专业安全评估。

⚙️ 使用说明

  • 输入 IP：运行 IP 溯源、目标 IP 检测、社区情报、整体画像
  • 输入域名：运行域名溯源、证书/CDN、社区情报、整体画像
  • 输入 URL：运行社区情报（URL 维度）
  • 网络环境页签：打开网站后自动检测当前访问 IP 的出口、VPN / 代理 / Tor 状态；可点“重新检测”刷新
  • “整体画像”页顶部显示质量评分圆环，并列出扣分依据
