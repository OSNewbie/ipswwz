关于

数据来源、使用说明

📌 数据来源（全部免费、无强制密钥）

  • tcp.lc：IP 归属、DNS、Whois、ICP 备案、SSL
  • ip.sb：备用地理与出口 IP
  • Shodan InternetDB：端口与漏洞测绘
  • Google DoH：DNS 综合解析（正反向）
  • crt.sh：证书透明日志子域名枚举
  • Domainee：SSL 深度检测（参数名 host）
  • checkip.me：VPN / 代理 / Tor / 风险评分
  • PhishDestroy：恶意域名风险评分
  • OTX / ContrastAPI / Feodo Tracker：社区威胁情报
  • apihz.cn pingplus：多地 Ping 节点解析

🔐 SSL 安全评分规则（满分 100）

  • 证书有效且未过期：+60
  • 协商协议 TLSv1.3：+20；TLSv1.2：+10
  • 剩余有效期 > 30 天：+10
  • 加密套件包含 GCM 或 CHACHA20：+10
  • 等级：A≥90 / B≥75 / C≥60 / D<60

🌐 CDN 识别说明

三层判定 + 多地 Ping：

  • CNAME 链：解析链中出现已知 CDN 域名特征
  • IP 段命中：A 记录 IP 落在 Cloudflare / CloudFront / Fastly / Akamai / Azure 等已知 IP 段内
  • 多地 Ping：通过免费 pingplus 接口从全球节点探测，收集不同地区解析出的 IP，再次进行 IP 段匹配
  • 厂商统计：按命中厂商聚合，柱状图展示每个厂商覆盖的 IP 数量

🎯 用户视角广告检测说明

模拟浏览器真实访问，分三阶段观察：0–3 秒快速弹窗、3–10 秒延迟加载、10 秒后滚动触发懒加载。

  • 预检：HEAD 请求探测 X-Frame-Options 与 CSP frame-ancestors
  • 观察时长：可选 10 / 15 / 20 秒，默认 15 秒
  • 可中断：随时点“停止”立即结束并保留已捕获信号

📊 质量评分规则

IP 评分：Feodo C2 命中 -35；OTX Pulse 每个 -5（最多 -20）；VPN/代理/Tor -15；高危端口每个 -5（最多 -20）；CVE 每个 -5（最多 -15）。

域名评分：PhishDestroy ≥70 -25，50–69 -15，30–49 -5；OTX Pulse 每个 -5（最多 -20）；SSL <60 -25，60–79 -10；缺 SPF -5；缺 DMARC -5；未备案 -10；广告联盟 -5；用户视角广告命中 -5。
