关于

数据来源、使用说明

📌 数据来源（全部免费、无强制密钥）

  • tcp.lc：IP 归属、DNS、Whois、ICP 备案、SSL（CORS 已启用）
  • ip.sb：备用地理与出口 IP
  • Shodan InternetDB：端口与漏洞测绘
  • Google DoH：DNS 综合解析（正反向）
  • crt.sh：证书透明日志子域名枚举
  • Domainee：SSL 证书检测
  • checkip.me：VPN / 代理 / Tor / 风险评分，CORS 已启用
  • PhishDestroy：恶意域名风险评分 0–100，无密钥、CORS Ready
  • OTX / ContrastAPI / Feodo Tracker：社区威胁情报

🔗 统一溯源说明

  • 输入域名：解析 A 记录得到 IP，对域名跑 Whois/DNS/ICP，对每个 IP 跑归属/端口/VPN 检测
  • 输入 IP：PTR 反向解析 + 反向 IP 查询得到域名，对 IP 跑归属/端口/VPN，对每个域名跑 Whois/ICP
  • 主目标展示完整模块，关联目标展示核心模块，最多各 3 个

📊 质量评分规则

IP 评分（满分 100）：Feodo C2 命中 -35；OTX Pulse 每个 -5（最多 -20）；VPN/代理/Tor -15；高危端口每个 -5（最多 -20）；CVE 每个 -5（最多 -15）。

域名评分（满分 100）：PhishDestroy 风险分 ≥70 -25，50–69 -15，30–49 -5；OTX Pulse 每个 -5（最多 -20）；SSL 无效 -25；缺 SPF -5；缺 DMARC -5；未备案 -10；广告联盟 -5；用户视角广告命中 -5。

分数与雷达图仅供参考，不能替代专业安全评估。
