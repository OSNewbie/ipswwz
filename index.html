关于

数据来源、使用说明

📌 数据来源

  • tcp.lc：IP 归属、DNS、Whois、ICP、SSL（允许跨域，日额度 1000 / 50 / 10每分钟 / 20 / 100）
  • ip.sb：备用地理与出口 IP（100 次/分钟）
  • Shodan InternetDB：端口与漏洞测绘（无密钥，约 1 req/s）
  • Google DoH：DNS 综合解析（A/AAAA/MX/NS/TXT）
  • crt.sh：证书透明日志子域名枚举
  • URLhaus / OTX / ContrastAPI / Feodo Tracker：社区威胁情报（无密钥）
  • Domainee：SSL 证书检测（无密钥，30 次/分钟）

⚙️ 使用说明

  • 输入 IP：运行 IP 溯源、社区情报（IP 维度）
  • 输入域名：运行域名溯源、证书/CDN、社区情报（域名维度）
  • 输入 URL：运行社区情报（URL 维度）
  • 隐私自检页面不依赖输入，打开即运行
  • 原始数据默认中文标签，字段名已翻译

🔐 隐私

本工具纯前端运行，不收集、不上传任何查询记录。所有请求直接发往第三方公开接口。
