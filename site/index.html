核心说明

🔀 IP / 域名互查逻辑
  • 输入 IP：跑 IP 全套（归属/ASN/BGP/端口/CVE/VPN/PTR/同 IP 域名），然后通过 PTR + 反向 IP 找到关联域名，自动对前 1 个域名跑 SSL/CDN/广告检测
  • 输入域名：跑域名全套（Whois/ICP/RDAP/DNS），然后解析 A 记录拿到 IP，自动对前 3 个 IP 跑归属/端口/CVE/VPN 检测
  • 证书页对 IP 输入会先用反查到的域名跑检测；没有关联域名则明确提示"该 IP 无关联域名，无法检测 SSL/CDN/广告"
  • 社区情报页 IP 和域名都跑 OTX Pulse + 恶意样本 + 最新漏洞；IP 额外跑 Feodo C2 比对
🌐 CDN 判定逻辑
  • 域名只解析出 1 个 IP：直接展示 ASN、运营商、BGP 前缀、国家，不做 CDN 判定
  • 解析出 2 个及以上 IP：才做 CNAME + ASN 白名单匹配，统计运营商占比
  • ASN 双源查询：ipwho.is 主源 + ipinfo.app 备源，永不显示"未知 ASN"
📢 广告检测 4 种方案
  • 方案1 · DNS CNAME 特征：直接查 CNAME 链是否指向广告联盟域名
  • 方案2 · 证书透明日志：通过 crt.sh 查所有证书子域名，匹配广告联盟域名和广告前缀子域名
  • 方案3 · iframe 模拟用户访问：预检 → 加载 → 多阶段观察弹窗、广告干预、iframe 高度突变
  • 方案4 · HTTP 头分析：预检时同时分析 X-Frame-Options 和 CSP
📊 评分规则
  • IP 质量分：基础 100 - VPN/代理/Tor 15 - C2 35 - 风险评分按档扣 - 高危端口每个 5（最多 20）- CVE 每个 5（最多 15）
  • SSL 评分：有效 60 + TLS1.3 20 或 1.2 10 + 剩余 >30 天 10 + 强套件 10
  • 域名质量分：基础 100 - PhishDestroy 25/15/5 - 广告评分按档扣（<60 扣 15 / 60-79 扣 8）- SSL <60 扣 25 / 60-79 扣 10 - 未备案 10 - OTX Pulse 每个 5（最多 20）
