CDN 判定与 ASN 查询说明

🌐 CDN 判定逻辑

  • 单个 IP：域名只解析出 1 个 IP 时，直接展示该 IP 的 ASN、运营商、BGP 前缀和归属国家，不进行 CDN 特征匹配（单 IP 通常意味着直连服务器，而非 CDN 边缘集群）。
  • 多个 IP：解析出 2 个及以上 IP 时，才进行 CDN 特征匹配（CNAME 链 + ASN 白名单），并统计运营商占比。
  • ASN 查询双保险：ipwho.is（connection.asn / connection.isp）为主源，ipinfo.app Atlas（as_number / as_description / cidr）为备源，两者都查不到时显示“归属查询受限”或“保留地址”，永不显示“未知 ASN”。
