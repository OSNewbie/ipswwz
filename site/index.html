关于

数据来源、使用说明

📌 数据来源（全部免费、无强制密钥）

  • tcp.lc：IP 归属、Whois、ICP 备案、SSL
  • ip.sb：备用地理与出口 IP
  • Shodan InternetDB：端口与漏洞测绘
  • Google DoH：DNS 综合解析
  • crt.sh：证书透明日志子域名枚举
  • Domainee：SSL 深度检测
  • checkip.me：VPN / 代理 / Tor / 风险评分
  • PhishDestroy：恶意域名风险评分
  • OTX / ContrastAPI / Feodo Tracker：社区威胁情报
  • Globalping：全球多地 Ping 探测
  • ipinfo.app：ASN 查询

🌐 CDN 多地探测识别

  • CNAME 链：解析链中出现厂商专属域名
  • ASN 归属：Cloudflare AS13335 / CloudFront AS16509 / Fastly AS54113 / Akamai AS20940 / Azure AS8075
  • 多地 Ping：Globalping 从全球多地并发探测，收集不同地区解析到的 IP
  • 只要 CNAME 或 ASN 任一命中即可判定厂商

🔐 SSL 安全评分规则（满分 100）

  • 证书有效且未过期：+60
  • 协商协议 TLSv1.3：+20；TLSv1.2：+10
  • 剩余有效期 > 30 天：+10
  • 加密套件包含 GCM 或 CHACHA20：+10
  • 等级：A≥90 / B≥75 / C≥60 / D<60

🕵️ 社区情报告警说明

每条告警包含问题描述、可能原因、建议处理。

📊 质量评分规则

IP 评分：Feodo C2 命中 -35；OTX Pulse 每个 -5（最多 -20）；VPN/代理/Tor -15；高危端口每个 -5（最多 -20）；CVE 每个 -5（最多 -15）。

域名评分：PhishDestroy ≥70 -25，50–69 -15，30–49 -5；OTX Pulse 每个 -5（最多 -20）；SSL <60 -25，60–79 -10；缺 SPF -5；缺 DMARC -5；未备案 -10；广告联盟 -5；用户视角广告命中 -5。
